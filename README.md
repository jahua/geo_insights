# GIS Project

This repository contains a GIS (Geographic Information System) project.

## Project Structure

- `data/`: Data files used in the project
- `docker/`: Docker configuration files
- `llm/`: Language model integration components
- `api/`: API code and endpoints
- `ui/`: User interface components
- `config/`: Configuration files
- `docs/`: Documentation
- `nb/`: Jupyter notebooks
- `scripts/`: Utility scripts
